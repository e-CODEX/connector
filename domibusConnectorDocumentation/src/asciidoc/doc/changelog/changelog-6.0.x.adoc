== Changelog for domibusConnector-6.0.x

=== 6.0.0-RC.1
==== Changes
* Migrate from Java 8 to 21
* Migrate from Spring Boot 2.5.15 to 3.3.3
* Update libraries and plugins to the latest version

==== Compatibility:
* The 6.0.x connector is compatible with the 4.1.3-RELEASE of the domibus-connector-plugin-Distribution (available via nexus: https://scm.ecodex.eu/artifactory/libs-release/eu/domibus/connector/plugin/domibus-connector-plugin-Distribution/4.1.3-RELEASE/)
