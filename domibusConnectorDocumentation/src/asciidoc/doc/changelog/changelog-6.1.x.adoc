=== 6.1.0
==== Changes
* N/A

==== Fixes
* Admin panel **Monitoring** JMS Queue UI: Fix broken "delete" and "restore" actions.

==== Technical
* Set up a database cleaning strategy. Cleaning cron job is defined via the
**connector.database.cleaning.cron** property key and uses Quartz-like cron expressions. The default value is **0 0 0 * * 7** (At 00:00 every Sunday).

==== Documentation
* Improve generated *HTML* and *PDF* documentation structure

==== Compatibility:
* The 6.1.x connector is compatible with the 4.6.0 version of the domibus-connector-plugin-distribution (available via JFrog: https://scm.ecodex.eu/artifactory/libs-release/eu/domibus/connector/plugin/domibus-connector-plugin-Distribution/4.6.0/)
